# FC Tweaks

FC Tweaks adds a **2x height** toggle to the Free Company member window. It
doubles the window height and the member list's visible row count, leaving
both widths unchanged. Click **1x height** to restore the original size; the window is restored automatically
when it closes.

The toggle appears in the upper-right of the member window.

## Build

Build with the Dalamud SDK installed by XIVLauncher:

```sh
dotnet build
```
